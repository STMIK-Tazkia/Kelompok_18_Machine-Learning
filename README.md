|Rangkuman Materi Machine Learning – Kelompok 18

Ringkasan Proyek  
Proyek ini menyajikan rangkuman terstruktur materi Machine Learning yang mencakup konsep dasar hingga metode lanjutan. Materi disusun untuk membantu mahasiswa memahami alur kerja machine learning secara sistematis, baik dari sisi teori maupun implementasi praktis, termasuk regresi, klasifikasi, clustering, serta evaluasi model.

Materi yang Dibahas

Konsep Dasar:
- Pengertian Machine Learning, metode, algoritma, dan model
- Supervised dan Unsupervised Learning

Metode dan Model:
- Regresi linier dan logistik
- Klasifikasi dan evaluasi model
- K-Means Clustering
- Gaussian Mixture Model (GMM) dan algoritma EM

Pendukung:
- Reduksi dimensi
- Tensor dan komputasi GPU
- Implementasi dasar menggunakan Python

Hasil dan Kesimpulan  
Berdasarkan rangkuman materi yang disusun, mahasiswa diharapkan mampu memahami konsep inti machine learning secara menyeluruh, mulai dari pengolahan data, pemodelan, evaluasi, hingga interpretasi hasil. Rangkuman ini dapat digunakan sebagai referensi belajar mandiri maupun pendukung diskusi akademik.
